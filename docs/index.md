# rpmbuilder docs

Guides and reference for [rpmbuilder](https://github.com/abn/rpmbuilder): a container image and a
small shell entrypoint that turn a directory of RPM sources into source RPMs and binary RPMs.

Start with the [usage guides](usage/index.md). Everything under [reference](reference/index.md) and
[project](project/index.md) is lookup and background material.

## Overview

- [What rpmbuilder is](overview.md) - The problem rpmbuilder solves, the three build paths it offers, and what it deliberately leaves out.

## Sections

- [Usage](usage/index.md) - Task-oriented guides: first build, spec and tito projects, repositories, certificates, debugging, and CI.
- [Reference](reference/index.md) - Environment variables, source configuration files, image tags, and container layout.
- [Project](project/index.md) - How the image and entrypoint work, the test suite, and how to contribute.
- [Change log](log.md) - What changed in this documentation bundle itself.
